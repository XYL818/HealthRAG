# 为什么需要这个文件
# ------------------
# fetch_wiki.py 靠搜索 API 拿候选条目，而搜索 API 返回的**常常是「兄弟条目」
# 而不是正主**：搜「抑郁症」拿回来的是产后抑郁症、季节性抑郁症、非典型抑郁症，
# 正主「重性抑郁障碍」一次都没出现过。于是语料里缺了一批最核心的条目。
#
# 这个清单是**从评测结果倒推出来的**：把 eval/questions.jsonl 的标准答案
# 和语料标题做差集，剩下的一律列在这里。所以它是有据可查的，不是拍脑袋补的。
#
# 一行一个标题。抓取时 redirects=1 会跟随重定向，命中的规范名和请求名不同时，
# 请求名会被记进 doc["aliases"] —— 检索和评测都认这个别名，
# 这样「抑郁症吃什么药」和「重性抑郁障碍」才能对上。

# 补采记录（第二轮）：上面 52 个标题里有 12 个没能入库，逐个查明原因后补在这里
#
# 三种原因，都不是「随便换个名字再试」：
#
# 1) 之前被消歧义误判（代码已修）。「吸烟」「睡眠」「体育运动」「食盐」的正文
#    开头是 hatnote（「此条目介绍的是…请见…」），而旧代码在**前 400 字**里找
#    「消歧义/可以指」，于是把 29KB 的「吸烟」、19KB 的「睡眠」整篇丢掉了。
#    现在只在正文**末尾**找标记（消歧义页的模板固定在底部）。
#    这三个直接列标题即可：
睡眠
运动
食盐
#
# 2) 常用名在中文维基上根本没有条目、也没有重定向，正主叫别的名字。
#    写成「常用名=实际标题」，抓回来时会把常用名记成别名，
#    这样检索和评测才认得出「抑郁症」和「重性抑郁障碍」是同一篇。
#    右列都是先用 API 的搜索接口查证过确实存在的标题：
久坐=坐姿與健康
体力活动=身體活動
热身运动=熱身運動
自动体外除颤器=自動體外去顫器
静脉曲张=靜脈曲張
抑郁症=重性抑郁障碍
钠=鈉
#
# 3) 确实补不齐的，留着并如实写进评测报告：
#    拉伸   —— 中文维基没有这个条目（搜「伸展運動」「牽拉運動」「柔軟度」都不存在），
#              但「运动之前要不要拉伸」这题的标准来源同时接受「热身运动」，故已覆盖。
#    鼻出血 —— 只有 395 字的短条目「流鼻血」/「鼻衄」，低于 MIN_CHARS=1200 的收录线，
#              宁可不收也不放一段残缺正文进去。这题在报告里保留为缺口。
